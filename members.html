Future Scope

A Site-Hosted Member Dashboard

The cards below sketch a possible future member dashboard hosted on this site. They are not currently buildable with the confirmed ChMS API (a shared Basic-Auth service account with no per-member login) — they'd require a separate, real per-member identity system layered on top. Today, signed-in members simply use ChMS's own site for their profile, groups, and events.
